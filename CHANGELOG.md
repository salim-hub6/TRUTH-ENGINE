# Changelog

All notable changes to TRUTH ENGINE are documented here.

A protocol version identifies a documented release; it does not imply independent scientific validation, uniform behavior across models, or proven performance improvement.

## [4.0.0] — 2026-11-13

### First public edition and repository publication package

- Published the provider-neutral, capability-aware TRUTH ENGINE v4.0 protocol in English, with a parallel Arabic translation.
- Added bilingual project landing pages and installation guides.
- Added session-level quick-start prompts in English and Arabic. These are explicitly not replacements for the full protocol.
- Added illustrative usage scenarios and an evaluation guide with a reproducibility record template.
- Added a project attribution notice for the public name `salim-hub6` and an explicit CC BY-SA 4.0 license notice with links to the canonical summary and complete legal code.
- Clarified that the protocol defines a 50-case core and 20-case additional evaluation framework by category; the repository does not yet contain 70 individually finalized test prompts or benchmark results.
- Preserved the v4.0 protocol text and its 48 numbered sections; the documentation package does not claim that new deployment or evaluation performance has been experimentally demonstrated.

### Protocol capabilities documented in v4.0

- Added a compatibility and deployment guide for hosted models, open-weight models, assistants, agents, sub-agents, chat interfaces, APIs, and orchestration frameworks.
- Explicitly stated that uniform behavior and performance across all models are not guaranteed, while establishing cross-model portability as an ongoing project objective.
- Added capability discovery and distinct execution levels: single-model multi-perspective reasoning, multiple calls to one model, and actual multi-agent or multi-model execution.
- Preserved the seven-layer epistemic-integrity architecture.
- Added the Constructive Critical Partnership rule: do not flatter at the expense of truth and do not disagree merely for disagreement's sake.
- Expanded evidence discipline to include multimodal material and explicit claim-status distinctions.
- Preserved the three debate roles and structured debate rounds.
- Added a coordinator and sub-agent operating contract covering task scope, permissions, evidence, output requirements, verification, and stopping conditions.
- Strengthened tool security and human-approval controls for actions with external impact.
- Added cross-model and cross-platform evaluation guidance.
- Clarified that the release is experimental and makes no claim of proven performance improvement or universal compatibility.

### Validation status

- The protocol structure and publication files were checked for expected files, section numbering, required links, encoding, and unresolved placeholders before publication.
- No claim is made that v4.0 has been independently benchmarked across providers or model families.
- Compatibility and effectiveness must be evaluated per model, version, configuration, and tool environment.

### Earlier design history

Earlier project discussions and drafts explored anti-sycophancy, hallucination resistance, evidence verification, confidence calibration, rational updating, causal reasoning, multi-agent debate, groupthink, prompt-injection resistance, and the seven-layer architecture. v4.0 consolidates and extends those design principles into a provider-neutral public protocol. Earlier drafts should be treated as historical design material, not as independently validated releases.
